# CodeType

Monkeytype uslubidagi matn va dasturlash kodi yozish mashqi.

## Ishga tushirish

- `index.html` faylini brauzerda oching (qo‘shimcha o‘rnatish kerak emas).
- Visual Studio Code: Live Server kengaytmasi bilan "Open with Live Server".

## Tuzilma

```
codetype/
  index.html
  css/style.css
  js/app.js
```

## Domen

`js/app.js` boshidagi `DOMAIN` o‘zgaruvchisini va `index.html` ichidagi canonical / og:url havolalarini o‘z domeningizga almashtiring.

## Joylash (hosting)

Papkani Netlify, Vercel yoki GitHub Pages ga yuklang, so‘ng domeningizni ulang.

## Ovoz

Ttepadagi 🔇/🔊 tugmasi ovozni yoqadi. Ovoz yoqilganda "tovush" qatori chiqadi:
Yumshoq, Mexanik, Membrana, Melodiya, Tomchi profillari va past / o‘rta / baland balandlik.
Ovozlar Web Audio bilan brauzerning o‘zida yaratiladi (tashqi fayl kerak emas).

## Lenta

Matn rejimida "ko‘rinish" → "Lenta": matn bitta uzun qatorda chiqadi, kursor joyida turadi, matn chapga suriladi.
